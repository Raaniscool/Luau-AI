# DukeOTR desktop assets

`dukeotr.ico` is original DukeOTR artwork generated by
[`scripts/generate_dukeotr_icon.py`](../../scripts/generate_dukeotr_icon.py). It contains the
16, 24, 32, 48, 64, 128, and 256 pixel PNG-backed Windows icon entries used by the native Tk
window, the PyInstaller executable, and the desktop shortcut.

No third-party logo, stock icon, model asset, or trademarked branding is included. The generator
is checked in so the binary asset can be reproduced and reviewed without an image editor.
